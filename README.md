# رَنّة

**لكل موعد رَنّة**

تطبيق عربي بسيط للتذكيرات، يساعدك على متابعة مواعيدك اليومية بوضوح دون حساب أو إعلانات.

## المزايا

- تذكير لمرة واحدة أو يومي أو متكرر
- تأجيل بمدة افتراضية أو مدة تختارها
- تخطي موعد اليوم مع استمرار التذكير المتكرر
- تأكيد الإنجاز بالسحب
- إيقاف التذكير المتكرر واستئنافه
- عرض التاريخ الميلادي والهجري
- واجهة عربية كاملة
- يعمل محليًا دون اتصال بالإنترنت

## التنزيل

يمكن تنزيل أحدث نسخة بصيغة APK من صفحة الإصدارات:

[تنزيل رَنّة](../../releases/latest)

> قد يطلب Android السماح بتثبيت التطبيقات من هذا المصدر.

## الخصوصية

لا يحتاج رَنّة إلى حساب، ولا يحتوي على إعلانات أو أدوات تتبع. تحفظ بيانات التذكيرات محليًا على الجهاز، وقد يشملها النسخ الاحتياطي لنظام Android وفق إعدادات الجهاز.

## المتطلبات

Android 8.0 أو أحدث.
