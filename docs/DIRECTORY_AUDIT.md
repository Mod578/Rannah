## 4. Risks, uncertainties, manual decisions

- **تذكير**: quarantined, not deleted. If you want it back: move it from the quarantine dir to
  `~/Projects/` (or re-extract `~/Downloads/تذكير.zip`). If you don't, delete the quarantine dir.
- **build-tools 35.0.0** (147M): not strictly required (AGP 8.7.3 defaults to 34.0.0), but
  plausible after any AGP upgrade with targetSdk 35. Kept; remove later via
  `sdkmanager --uninstall 'build-tools;35.0.0'` if space matters.
- **`~/Android/gradle-8.11.1`** (146M): technically redundant once the wrapper exists (the wrapper
  dist in `~/.gradle` is what `./gradlew` runs). Kept as the standalone Gradle for wrapper
  regeneration; delete later if you accept re-downloading in that scenario.
- **No git repo exists** for Bal — there was never any Git history to lose, but this also means no
  version-control safety net. Recommended next step: `git init` + first commit.
- **No release keystore exists yet** — release APKs are unsigned. Publishing needs a keystore
  (keep it out of git; `.gitignore` now excludes keystores).
