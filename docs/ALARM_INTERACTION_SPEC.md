# مواصفة تفاعل المنبّه: رَنّة

## القاعدة التي تحكم كل ما تحت

> **إيقاف الصوت يوقف الصوت. لا شيء غير ذلك.**

المنبّه يرنّ عند شخص نصف نائم، في الظلام، وصوتٌ عالٍ في أذنه. اللمسة في تلك اللحظة ليست دليل
نيّة، بل دليل رغبة في إسكات الضجيج. لذلك لا يجوز أن يكون إسكات الضجيج طريقًا — لا مقصودًا ولا
عرضيًا — لتسجيل أن مهمة في العالم الحقيقي قد تمّت.

هذه القاعدة كانت مخروقة بخيار اسمه «عند إيقاف المنبّه اعتبره منجزًا». حُذف الخيار، وحُذف عموده
من قاعدة البيانات (ترحيل ٣→٤)، وحُذف مساره في `ReminderScheduler`. الاختبار
`stopping the sound never records a completion` يمنع رجوعه.

## التسلسل على الشاشة

بالترتيب الذي يقابله المستخدم:

### ١. تأجيل — الأساسي، الأكبر، القابل للعكس

```
تأجيل ١٠ دقائق        [زر ممتلئ، ارتفاع ٨٨dp]
تغيير مدة التأجيل      [زر نصي، ٤٨dp]
```

أكبر عنصر على الشاشة. أسلم ما يُعطى لمن ليس مستعدًا للقرار هو طريقة للتأجيل، لا طريقة للرفض.
المدة تتبع إعداد التذكير نفسه. تغييرها يفتح **حوارًا مركّزًا واحدًا** (٥ / ١٠ / ١٥ / ٣٠)، لا
صفًّا من الأزرار يزاحم الإجراء الذي يعدّله.

### ٢. اسحب للتأكيد — الإنجاز، متعمَّدًا

```
اسحب للتأكيد: سجلت البصمة
اسحب الدائرة إلى آخر الشريط لتأكيد الإنجاز
```

النص **هو عبارة الإنجاز نفسها**، لا «تم» مجردة: المستخدم يقول ما فعله، ورَنّة تكتب ما قاله.
للقوالب: «سجلت البصمة» / «أخذت الدواء» / «تم الدفع» / «تم الاتصال». وإلا: «تم الإنجاز».

خصائص `SlideToConfirm`:

| المطلب | التنفيذ |
| --- | --- |
| حركة أفقية متعمَّدة | `detectHorizontalDragGestures` عبر كامل عرض الشريط |
| هدف إبهام كبير | دائرة ٦٤dp داخل شريط ٧٦dp |
| تقدّم مرئي | الشريط يمتلئ بنسبة المسافة |
| رجوع آمن | الرفع قبل النهاية يعيد الدائرة (‎180ms) ولا يسجّل شيئًا |
| اهتزاز عند العتبة | `HapticFeedbackType.LongPress` عند الوصول |
| منع التكرار | `confirmed` يُقفل عند العتبة؛ السحب المستمر أو الثاني لا يفعل شيئًا |
| RTL صحيح | `Alignment.CenterStart` و`placeRelative` يعكسان تلقائيًا؛ إشارة دلتا السحب وحدها تُقلب |
| مفهوم بلا حركة | النص يحمل المعنى كاملًا؛ الامتلاء تغذية راجعة لا رسالة |
| بديل وصولي | إجراء نقر عادي في طبقة الدلالات: قارئ الشاشة أو Switch Access يؤكد بتفعيل واحد، بلا محاكاة سحب |
| لا يعتمد على اللون | الكلمة هي الحالة |

**ليس محاكاة لفتح القفل**: شريط معنون يمتلئ، لا سكة عارية بسهم. المستخدم يؤكد واقعة، لا يفتح
جهازه، ويجب ألا يتشابه الشعوران.

### ٣. إيقاف الصوت فقط — ثانوي، وصادق عن حدوده

```
إيقاف الصوت فقط                                  [زر محدَّد، ٦٠dp]
إيقاف الصوت لا يُسجَّل إنجازًا، وستسألك رَنّة بعده.   [مع المتابعة]
إيقاف الصوت ينهي هذا التنبيه دون تسجيل إنجاز.      [بدون متابعة]
```

الجملة تحت الزر تتغيّر بحسب التذكير، فيعرف المستخدم ما سيحدث **قبل** أن يضغط، لا بعده.

عند الضغط:
1. النغمة والاهتزاز يتوقفان فورًا.
2. **لا يُسجَّل إنجاز إطلاقًا.**
3. مع المتابعة: الحدوث ينتقل إلى «بانتظار تأكيدك» ويظهر إشعار المتابعة وبطاقة الشاشة الرئيسية.
4. بدون المتابعة: سؤال هادئ لمرة واحدة، والحدوث يبقى غير محسوم — لا منجزًا ولا فائتًا كذبًا.

## ما لا يوجد على الشاشة

- لا إجراء مدمّر (لا حذف، لا إنهاء تكرار).
- لا إجراء بأيقونة وحدها.
- لا شريط تنقّل.
- لا محتوى ثانوي غير الحالة والموعد والعنوان.

## الحالة والمحتوى

```
[العلامة]
المنبّه يرنّ الآن            ← الحالة بالكلمات، لا باللون
١:٠٦ ص                      ← الساعة الآن (تُحدَّث كل ١٠ ثوانٍ)، لا وقت الحدوث
بصمة الدوام                 ← العنوان
كل يوم عمل، الساعة ٧:٠٠ ص   ← سياق الجدولة، سطر واحد
```

الساعة الحالية لا وقت الحدوث: أول سؤال في الخامسة فجرًا هو «كم الساعة الآن؟».

## عدم التكرار (Idempotency)

طبقتان:

1. **`AlarmViewModel.resolveOnce`** — قفل `resolving` يمنع إطلاق كوروتين ثانٍ أصلًا من نقرة
   مزدوجة أو نشاط مُستعاد أو نيّة مُعاد تسليمها. يُفتح فقط عند حدوث جديد.
2. **`ReminderScheduler`** — فهرس فريد على `(reminderId, occurrenceAt, status)` يجعل السجل
   نفسه لا يتكرر مهما تكرر الاستدعاء.

`SlideToConfirm` يضيف طبقة ثالثة بقفل `confirmed` عند العتبة.

## تسلسل الإشعار العادي (لا منبّه)

1. **تم الإنجاز**
2. **تأجيل**
3. فتح التفاصيل

التمرير بعيدًا (dismissal) **ليس إنجازًا**: `onNotificationDismissed` يفتح المتابعة إن كانت
مفعّلة، وإلا يسجّل «تجاهلته» — لأن التنبيه وصل فعلًا ودُفع جانبًا، وهذا ليس نفس «فات الموعد».

## الشاشة الكاملة: ما يُدَّعى وما لا يُدَّعى

- Android 14+ يقصر `USE_FULL_SCREEN_INTENT` على التطبيقات التي جوهرها المنبّهات أو المكالمات.
  رَنّة منبّه، لكن القرار ليس لها.
- عند غياب الإذن أو رفض الشركة المصنّعة: **بديل عالي الأولوية** — إشعار بأولوية قصوى مع
  استمرار الصوت. لا تُفقد الوظيفة، يُفقد العرض.
- `showWhenLocked` + `turnScreenOn` + `requestDismissKeyguard` مضبوطة، و`launchMode
  =singleInstance` يبقي شاشة واحدة لكل حدوث رنين.
- **لا يُدَّعى أن الشاشة الكاملة تعمل على كل جهاز أو كل شركة.** أوضاع توفير الطاقة الصارمة عند
  بعض المصنّعين توقف التنبيهات المجدولة، وهذا خارج ما يمكن للتطبيق ضمانه.
